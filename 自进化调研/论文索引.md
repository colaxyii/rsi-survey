# 论文索引

> 本页由 Dataview 自动生成，不需要手动维护。
> 新增论文笔记后，只要 frontmatter 里有 `tags: [paper/...]`，就会自动出现在下面。

## 全部论文

```dataview
TABLE WITHOUT ID
  file.link AS "论文",
  year AS "年份",
  venue AS "发表",
  status AS "状态"
FROM "自进化调研" OR #paper
WHERE contains(string(tags), "paper/")
SORT year DESC, file.name ASC
```

## 已精读（status: digested）

```dataview
LIST
FROM #paper
WHERE status = "digested"
SORT file.mtime DESC
```

## 待读（status: reading）

```dataview
LIST
FROM #paper
WHERE status = "reading"
SORT file.mtime DESC
```

## 可对外分享（publishable: true）

```dataview
TABLE WITHOUT ID
  file.link AS "论文",
  join(filter(tags, (t) => startswith(t, "paper/")), ", ") AS "主题"
FROM #paper
WHERE publishable = true
SORT file.mtime DESC
```

---

## 按主题分组

```dataview
TABLE WITHOUT ID
  join(filter(tags, (t) => startswith(t, "paper/")), ", ") AS "主题",
  length(rows) AS "篇数",
  join(rows.file.link, " · ") AS "论文"
FROM #paper
GROUP BY join(filter(tags, (t) => startswith(t, "paper/")), ", ")
SORT length(rows) DESC
```
